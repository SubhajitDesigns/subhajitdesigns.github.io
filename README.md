# Subhajit Portfolio — Free Static Version

This is a standalone HTML/CSS/JS portfolio inspired by the structure and interaction style of the reference portfolio.

## Files
- `index.html` — page structure/content
- `style.css` — layout, typography, animation, responsive styles
- `script.js` — cursor + reveal animations
- `assets/` — your uploaded portfolio images

## Run locally
Double-click `index.html`, or use VS Code + Live Server.

## Publish for ₹0
Use GitHub Pages:
1. Create a GitHub account.
2. Create a public repository named `subhajit.github.io` (replace with your GitHub username if different).
3. Upload all files from this folder.
4. In the repository, open Settings → Pages.
5. Select the main branch as the source and save.
6. GitHub will provide your free `github.io` address.

## Before publishing
Replace the placeholder email and the `#` social links in `index.html` with your real contact links.
